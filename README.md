FACE RECOGNITION ATTENDANCE SYSTEM

## Project Overview

The Face Recognition Attendance System is a Python-based computer vision application that uses OpenCV and LBPH face recognition to identify students and automatically record their attendance.

## Features

- Student registration
- Face image capture
- Face training using OpenCV
- Real-time face recognition
- Automatic attendance marking
- Attendance records stored with date and time
- Student details management

## Technologies Used

- Python
- OpenCV
- Haar Cascade Classifier
- Face Recognition
- CSV / File Handling
- Tkinter

## Project Structure

- AMS_Run.py – Main application
- training.py – Trains the face recognition model
- testing.py – Tests face recognition
- TrainingImage/ – Stores captured face images
- TrainingImageLabel/ – Stores the trained model
- Attendance/ – Stores attendance records
- StudentDetails/ – Stores student information
- Haar Cascade XML files – Used for face detection

## How It Works

1. Register student details.
2. Capture multiple face images of the student.
3. Train the face recognition model.
4. Start face recognition.
5. The system identifies the student.
6. Attendance is automatically recorded with date and time.

## Purpose

The main purpose of this project is to automate the traditional attendance process using face recognition technology and reduce manual attendance work.

## Future Scope
